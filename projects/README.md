# Projects

End-to-end projects that apply a chapter's methods to real data: ingestion, transformation, analysis and a data-visualization story. At least one per chapter.

Each project gets its own folder (`projects/<short_name>/`) with a `README.md` stating the question, the data source, the methods and chapter(s) it draws on, and the findings. Exercise-sized spin-offs that stay close to one book exercise live next to that exercise as `extra-*` instead.
